# What the cloud session needs from the Mac

> ⚠⚠ **STOP. DO NOT RUN `generate_numbers.py` FROM `main` AS THIS FILE
> ORIGINALLY INSTRUCTED.** On `main` that script **truncates** `NUMBERS.tsv`:
> it opens the file with `"w"` and writes only the keys it computes. On
> 2026-09-17 the file held **101 figures while the script built 66**, so a plain
> run **silently deleted 35**, including every `controls.*` constant and the six
> `rm.*` keys carrying the Gate 1 window, its brackets, the in-window IQR and
> the floor sensitivity.
>
> The fix exists but **is not on `main`**. It is on
> `origin/worktree-clip2-review`, which rewrites the write as a merge: computed
> keys refresh in place, keys the script does not build are kept, and carried
> figures are named on stdout. Take one of these routes before running anything:
>
> **Route A, safest.** Back up first, then run, then compare:
> ```
> cd ~/bp-recombination-aware-snps
> cp NUMBERS.tsv NUMBERS.tsv.bak
> wc -l NUMBERS.tsv.bak
> python3 generate_numbers.py
> wc -l NUMBERS.tsv          # if this dropped, restore from the .bak
> ```
>
> **Route B, better.** Take the merge-write version first, then run:
> ```
> git fetch origin worktree-clip2-review
> git checkout origin/worktree-clip2-review -- generate_numbers.py
> cp NUMBERS.tsv NUMBERS.tsv.bak
> python3 generate_numbers.py
> ```
>
> I wrote the original instruction without knowing this, and it would have
> destroyed 35 hand-computed figures. Apologies for the near miss.

## 1a. Where the files are

**All at the top level of the project folder, beside the `.py` scripts.** Every
one of these scripts resolves its paths from its own directory, so there are no
subfolders to hunt through.

```
~/bp-recombination-aware-snps/NUMBERS.tsv
~/bp-recombination-aware-snps/GROUPING_LADDER.tsv
~/bp-recombination-aware-snps/GROUPING_PREDICTIONS.tsv
~/bp-recombination-aware-snps/RESOLUTION_CURVE.tsv
~/bp-recombination-aware-snps/EXPOSURE_OVERRIDES.tsv
```

**They are not in the git repository and never have been.** `.gitignore` carries
a blanket `*.tsv`, and `git ls-files` returns zero tracked `.tsv` files, which is
the same rule the `no-data-tracked` CI job enforces. So a clone of this
repository does not contain any of them. They reached the Mac in the curated
bundle, whose file list was built by grepping data filenames out of the `*.py`
sources, which picks up all five.

Confirm they are present before running anything:

```
cd ~/bp-recombination-aware-snps
ls -l NUMBERS.tsv GROUPING_LADDER.tsv GROUPING_PREDICTIONS.tsv \
      RESOLUTION_CURVE.tsv EXPOSURE_OVERRIDES.tsv
```

`NUMBERS.tsv` is regenerated by the command above, so it is the one file that
does not need to pre-exist. If either `GROUPING_*` file is missing, it is
because `grouping_test_bp.py` only began persisting them on 2026-08-23, and
re-running that script writes both. If `RESOLUTION_CURVE.tsv` is missing,
`resolution_curve_bp.py` writes it.

| file | what it settles |
|---|---|
| `NUMBERS.tsv` | every quotable figure, with its `QUOTE THIS` / `DO NOT QUOTE` annotations |

All four are text and small. None contains isolate-level sequence.
