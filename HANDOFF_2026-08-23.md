## 2. What this session did (the summary)

Everything below was verified by re-running, not asserted.

- **Accessory-genome attribution — tested, and it fails its controls.** Looked
  positive (country 30% vs core 21%) but 0/13 where a close relative exists, 5×
  sensitive to assembly quality, and the whole margin rests on two Mississippi
  reference genomes. The core result is strengthened. (`ACCESSORY_ATTRIBUTION_RESULT`)
- **r/m resolved twice.** 7.38 vs 7.26 was an A100-vs-workstation *partition*
  difference (not hardware). Then Gate 1's window was found to be applied through
  a Mash proxy in the wrong unit system; recomputed on alignment distances the
  window is [700, 4700] and **r/m is 7.70**, not 7.26. (`GATE1_ALIGNMENT_RESULT`,
  `rm_provenance/`)
- **`strain_1_L1_26` is a clonal expansion, not a floor artifact** — settled by
  Gate 2 (mean pairwise 72 SNPs, continuous). Along the way found
  `L1v4c_out/Clusters` is a hybrid 88-dir directory that double-counts 153
  genomes — the root cause of the repeated corrections. (`REDERIVATION_RESULT`)
- **The basis was frozen** (§0) after auditing every table for partition
  keying; `DISTANCES_v4c_SUMMARY` and `CGMLST_CONCORDANCE` were mixed and are now
  correct by restriction. (`FINAL_BASIS_2026-08-22/README.md`, `DOWNSTREAM_IMPACT`)
- **Workspace tidied** 605 → ~330 top-level files, in three stages, each verified
  by re-running. Rule learned: never retire a git-tracked file on a reachability
  test (tracked = a human keep decision). (`RETIRED_2026-08-22/README.md`)
- **Phase 1 expansion declined** on evidence: a free downsampling control showed
  region survives a 90× rebalancing (κ 0.83→0.77) — not a panel artifact — and
  country never lifts off baseline. More references buy nothing.
  (`DOWNSAMPLING_CONTROL_RESULT`)
- **Track 0 (validation-power acquisition) run and integrated.** +Portugal→
  Thailand (a genuine close-relative country hit) and +2 Mississippi autochthonous
  → USA. This required **leave-outbreak-out** (an explicit same-source register,
  `OUTBREAK_GROUPS.tsv`; NOT automatic — the Vietnam/Georgia lineage case proved
  automatic wrong). North America is now testable and the Mississippi US-origin
  genome misattributes to Latin America — correct at the deep splits, wrong at the
  shallow ones, the depth thesis in one genome. (`TRACK0_INTEGRATION`,
  `LEAVE_OUTBREAK_OUT`)
- **Citations audited** — a PMID cited as "Pearson 2020" was a materials-chemistry
  paper about formic acid on ceramics; "Ashcroft 2021" is a phantom (= Lichtenegger).
  Fixed across the corpus.
- **Corpus prose swept and the manuscript outline reconciled** — every attribution
  figure now carries an analysis-provenance tag ([SNP/24], [cg-Licht/46], …).

**Recurring lesson, stated because it paid off repeatedly:** the value came from
*verifying* (re-running, reading the actual artifact, checking distances/sources)
rather than trusting a plausible number. Nearly every correction this session —
the r/m proxy, the hybrid directory, the Mississippi leak, the Vietnam/Georgia
counterexample, four separate scorer leaks — was caught that way, not by
reasoning from summary statistics. Read `git status` before every commit; compute
every number at the moment you write it.
