## What closed today

**The `gubbins_seed` fix is real now.** It had been recorded as done in six
documents since 2026-08-19 and had never existed. Released as `v1.1.0-mod`:

- `gubbins_seed = 20260904` passes `--seed` at all five `run_gubbins.py` call
  sites, closing the unseeded `randint(0, 10000)` draw that hits 0 about one
  time in 10,001 and silently drops a unit while the run exits 0.
- `gubbins_deterministic = false` forces `--threads 1`. This is the correction
  the measurement forced: **a seed alone is not determinism.** Ten units, two
  runs each, four output files compared byte for byte gave 4/10 identical with
  no seed at 4 threads, 5/10 with a seed at 4 threads, and 10/10 with a seed at
  1 thread. The five that agreed under a seed are the same five that agreed
  without one. Thread count dominates. Determinism costs about 2x and is opt-in.
- Both Gubbins paths are wired. `GUBBINS_CLUSTER` produced the reported
  analysis; `RECOMBINATION_GUBBINS` produced no reported result and was wired
  anyway so one parameter governs both. Doing so surfaced that the classic
  module passed no `--threads` at all and had been silently single-threaded
  while carrying a `process_medium` label.

**The pipeline repository has CI**, four jobs, none needing isolate data. It had
none before, which is how a documented fix that never existed survived weeks.

**The review layer is under version control.** `REVIEW_*.md` at the top level of
the analysis repo, not a `REVIEW/` subdirectory, because `.gitignore` re-admits
only top-level files by extension and that rule is load-bearing. Before today
those five documents existed only inside the package directory in `~/Downloads`.

## Three things worth distrusting, because they were nearly wrong

**The seed CI check was written wrong twice, and both wrong versions passed the
positive test.** The first used a line window wide enough to see an adjacent
call site's seed. The second matched a single trailing backslash where the
Groovy script block emits two, so it matched zero call sites and passed over an
empty set. It now scopes to the backslash-continued command block and asserts it
found at least 5 invocations. It was verified by deleting a seed and confirming
exit 1. **Treat "we added a check" with the same suspicion as "we made a fix."**

**The reference audit was reporting the wrong list.** It read to end of file
instead of stopping at the next heading, so the manuscript's seven-item
submission checklist, which restarts numbering at 1, had overwritten references
[1] through [7]. Separately, `NO-METADATA` tested for the literal string
`"vol."`, which no entry in this manuscript uses, so it fired on all 24. Both
fixed. The audit went from 24 of 24 flagged to 2.

**`v1.1.0-mod` was moved more than once on the day it was created.** The first
placement was on a red build. No pipeline code differs across those commits;
only CI and `PROVENANCE.md` changed. Resolve it with
`git rev-list -n1 v1.1.0-mod`, not from any transcribed SHA.

## Two things that have not changed and are easy to get wrong

**The reported analysis is `v1.0.5-mod` at `79ab645`, and it is not
seed-reproducible.** `v1.1.0-mod` adds the determinism controls, but re-running
the reported analysis under them produces a different run rather than validating
the pinned one. This is not recoverable and belongs in the Methods, stated once
and plainly. The `v1.0.5-mod` tag message is itself wrong about why, claiming the
commit "predates the `gubbins_seed` fix" when no such fix existed anywhere until
today; `PROVENANCE.md` is the correction of record, because retagging a published
release to fix prose is worse than leaving it.

**Units.** Gate 1's window is `[700, 4700]` mean pairwise core SNPs on the
**alignment** basis, and the Mash proxy misplaced 22 of 85 units. Quote r/m
**7.70** in-window on the frozen basis, never the all-unit median, which averages
real measurements with detection failures. The estimator is part of every
attribution number: `nearest_nb` is country's best and `modal_k20` is region's,
and mixing them produces a figure that belongs to neither.
