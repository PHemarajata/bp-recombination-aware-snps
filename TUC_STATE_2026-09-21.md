## 6. Questions for the session that has been working on clip 4

Asked because that work is **not committed**. The only new commit on
`docs/film-work-2026-09` is `49bfece`, the workstation request, and nothing in
it names a confirmed clip 4 narration error. So the corrected clip 4 exists only
in that session's context, and the work cannot be finished or verified without
these answers.

**Q1. What exactly is the correction?** The act, the line as it is now, and the
line as it should be. Verbatim, because it has to go into `spec_v2.json` in
spoken form and the caption is derived from it.

**Q2. Is it B4?** Clip 4 act 7 says "the Kawang framework" on screen and "the
closeout framework" in the narration for the same thing. That is the only
candidate visible from here that is both a one-line re-synth and a picture
re-render. But the workstation request itself says B4 is *waiting on the deck*
to say what the framework is called, so if the wording was chosen without that
answer, say what it was chosen from.

**Q3. What changes in the picture?** Which scene class, which string, and
whether anything moves. A text swap of equal length needs no re-timing; a longer
string can push a line into the reserved bottom eighth or across the band edge,
and both have shipped as defects before.

**Q4. Has anything already been rendered or synthesized?** If parts or voice
files exist, say where. Re-synthesizing costs credits and re-rendering costs
half an hour, and neither should happen twice.

**Q5. Are any scene files edited but uncommitted?** Specifically
`tuc_clip4_scenes.py`. A re-render from this branch would silently use the old
version and produce a film that looks corrected but is not. This is the single
most damaging thing that could go wrong, so answer it even if the answer is no.

**Q6. Anything else uncommitted?** Findings, decisions, half-finished edits. The
repo `.gitignore` denies by default, so uncommitted work is invisible to
`git status` as well as to other sessions. That is exactly how
`Act4NotSeparable`'s source was lost.
