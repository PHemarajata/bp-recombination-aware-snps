# Document map

All 93 documents in `repository/`, grouped by what they are for.
Nothing has been removed. Where a document is superseded or carries a known
hazard, the status column says so; that is the column to read before trusting
a number you find in one.

**A note on how this project keeps records.** Superseded results are kept visible
under correction banners rather than deleted, so a correction can be audited. The
cost is that a document read top to bottom can present a superseded number before
its correction. That is the single most likely way to be misled here.
